SMART KDAT V11 — AI SUMMARY FIRST

WHAT CHANGED
1. Removed the Keseluruhan Data / Data Explorer page from the package.
2. SMART KDAT now answers in a natural summary FIRST.
3. Supporting table appears AFTER the answer.
4. Improved understanding for:
   - count / how many
   - Karnival Komuniti
   - state
   - implementation status
   - month
   - "sehingga / hingga / sampai" month ranges
   - year when mentioned
   - participants
   - cost
   - top state ranking
5. For "hingga September", records from January through September are included when month data is available.

Example:
User: Berapa banyak Karnival Komuniti di Sabah telah dilaksanakan sehingga September?
Bot: Berdasarkan rekod SMART KDAT, sebanyak [COUNT] Karnival Komuniti telah dilaksanakan di Sabah sehingga September [YEAR].
Then: supporting records table.
